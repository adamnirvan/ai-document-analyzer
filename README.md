
# AI Document Analyzer

An AI-powered SaaS application for analyzing PDF documents.

## Tech Stack

### Frontend
- React
- Vite
- Tailwind CSS

### Backend
- Node.js
- Express.js
- PostgreSQL
- Prisma

### Infrastructure
- Redis
- RabbitMQ
- Docker
- AWS

## Project Structure

- frontend: User interface
- backend: REST API and business logic
- docker-compose.yml: Container orchestration
